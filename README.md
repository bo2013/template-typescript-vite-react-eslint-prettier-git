# TypeScript + Vite + React + ESLint + Prettier + Git Template

## Features

- **Vite:** Modern frontend build tool
- **React:** Library for building user interfaces
- **TypeScript:** JavaScript with static type checking
- **ESLint:** Find and report JavaScript/TypeScript code issues
- **Prettier:** Code formatter that enforces consistent formatting
- **Git:** Distributed version control system

## How to use

### Method 1: Use this template

Click [**Use this template**](https://github.com/bo2013/template-typescript-vite-react-eslint-prettier-git/generate).

### Method 2: Clone the repository

Open your shell and run:

```
git clone https://github.com/bo2013/template-typescript-vite-react-eslint-prettier-git
cd template-typescript-vite-react-eslint-prettier-git
```

> [!WARNING]
> This repository contains a workflow designed to update packages.
> **Remove `.github/workflows/update.yml` after creating a repository from this template.**

## Enjoy!
